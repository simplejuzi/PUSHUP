## 四、⚠️ 一个容易踩的坑：数据不会自动跟着走

App 的数据**只存在打开它的那个浏览器 / 手机本地**（localStorage），不上传、不同步。所以：

- 交接包里的源码打开后，是**预置了最初 19 条历史记录**的干净一份（2026/10/07 – 11/09）。
- 如果你在云端线上版里**又录过新数据**，换电脑前先去「我的 → 导出备份 JSON」下载一份，再到本地「导入数据」粘贴进去。
- 反过来也一样：以后本地录的数据想带回手机，同样用导出 / 导入。
