## 0. 一句话

用户要一个记录每天俯卧撑（及少量徒手动作、体重、臂围）的手机 App，要求**页面简洁好看、用市面上好看的 UI**。已迭代 6 版原型 + 1 个正式版并上线 PWA。当前用户要求：**Logo 用默认橙标、关掉「更换 Logo」功能、上传 GitHub、打包 APK**。前两项已完成，后两项因云端环境限制未做完，需要你在本地继续。

## 1. 用户是谁、怎么沟通

- 用户是**普通用户，不是开发者**，全程用大白话提需求，经常一句话里塞好几件事。
- **务必把大白话翻译成实际功能**，不要逐字照做。历史成功案例：
  - 「我的页面去哪了」→ 不是找页面，是**把漏掉的「我的」页补回来**
  - 「有变化在显示出来」→ 动作库「完成」按钮**只在常用动作被改动后才浮出**，平时不显示
  - 「常显示的完成动作按钮不要」→ 同上
  - 「数据用户可以详细查看哪一天的数量」→ 图表**点选/滑动 → 下方出当天明细卡**
  - 「主题跟随系统」→ 加第 3 个选项 `跟随系统`，读 `prefers-color-scheme` 并监听变化
- 用户**先看方案和页面预览图，确认后再让做成 App**。原型阶段每轮都生成了 `.html` 原型 + 多张 PNG 预览图 + 截图自检。
- 用户明确说过「**数据页面很好，暂时不动**」——后续多轮都只加交互（点选、滑动浮层），**四张 KPI 卡、柱图、折线、臂围对比的样式和数字一个没改**。这条约束仍然有效，别擅自重做数据页视觉。
- 用户说「我看了下没有问题」= 定稿。
- **回复用简体中文**，简洁直接，别堆术语；交付时给可点文件 + 预览图。

## 4. 功能清单（v1.0 现状）

**5 个 Tab**：记录 / 历史 / 数据 / 动作 / 我的

- **记录**：一天可记多个动作；每行大数字输入 + 单位 + 快捷值 + 4 个步进按钮（减到 0 不变负）；体重/臂围选填，空时提示「今天没测 · 上次 xx」；日期左右切换可补录任意一天；空值不保存；保存即改。默认常用 5 项中 3 项是俯卧撑（标准/跪姿/钻石），首项永远是标准俯卧撑。
- **历史**：月历热力（有记录的日子直接显示次数）、点日期看详情/补录、按月汇总、倒序列表、可编辑删除。
- **数据**：累计/日均/最高/连续天数四张 KPI 卡 + 俯卧撑柱状图 + 体重折线 + 臂围对比 + 每日目标环；**柱子和折线点可点选** →「当天详细记录」卡（列出当天所有动作、体重臂围备注、编辑这天、左右翻天）；**体重折线可左右滑动**看每次测量值（浮层显竖线+高亮点+体重/日期，联动明细卡）。⚠️ 视觉不许改。
- **动作**：53 个内置动作，按分类/难度筛选、搜索中英文名/肌群/器械；每张卡带中英文名、难度、单位徽章、肌群、器械、分类、要点、建议量、常用开关；**「⭐ 我的常用」独立筛选**，全部视图拆成「已勾选 / 未加入常用·按分类」两大段；可**新增自定义动作**（名称/英文名/归入分类或新建分类/单位/难度/器械/肌群/建议量/快捷值/要点/是否加入常用），带蓝色「自定义」标签、可删除；**「完成」栏只在改动后出现**。
- **我的**：数据统计；导出备份 JSON（含记录/常用/主题/自定义动作/分类）、导出 CSV（Excel 可开）、导入（粘 JSON 备份或直接粘 `11.08 俯卧撑200 体重55.40 臂围29` 文本，同日期覆盖合并）；外观 浅色/深色/**跟随系统**；关于（软件介绍、v1.0 正式版、作者「再多吃一口饭」、[酷安主页](https://www.coolapk.com/u/2456761)）。
- **开屏**：每次打开全屏展示，深色渐变 + 橙色光晕 + 大引号 + 大字语句；**12 句固定词库顺序循环**（localStorage 记序号）；2.6 秒自动进入，点任意处/「开始训练 →」跳过；底部一句**实时数据激励**（6 句轮换）。**没有进度点**。⚠️ 淡入透明度动画曾导致慢速环境下文字停在半透明，已彻底移除 `fadeIn`，只保留 `@keyframes up` 位移入场，文字颜色恒定 —— 别再加透明度动画。
- **PWA**：`manifest` + `sw.js`（缓存名 `pushup-v2`）+ 192/512/maskable/Apple 全套图标；可添加到主屏幕、离线可用；独立窗口隐藏模拟状态栏、适配刘海/底部安全区。

**53 个动作分类**（来源：BigBeeFit 俯卧撑变式、SELF 53 个自重动作、Calisthenics Association 进阶表等）：
- 上肢推 14：靠墙、上斜、跪姿、离心、标准、宽距、窄距、钻石、下斜、折体(派克)、蜘蛛、弓箭手、击掌俯卧撑、凳上臂屈伸

- 下肢臀腿 12：自重深蹲、臀桥、单腿臀桥、行进臀桥、臀桥保持、反向弓步、侧弓步、保加利亚分腿蹲、靠墙静蹲、深蹲跳、站姿提踵、侧卧抬腿

## 5. 技术架构与关键实现

- **单文件**：`app/index.html` 约 85 KB，HTML + CSS + JS 全内嵌，**零外部依赖、零 CDN**，断网完整渲染。
- **纯前端存储**，localStorage 键：
  - `fitness_proto_v03` → 记录数组 `DATA`
  - `fitness_favs_v03` → 常用动作 id 数组 `FAVS`
  - `fitness_theme_v03` → `light|dark|auto`
  - `fitness_custom_v04` → 自定义动作数组 `CUSTOM`
  - `fitness_cats_v04` → 自定义分类（`cc-` 前缀）
  - `fitness_splash_v04` → 开屏词库序号
  - `pushup_logo_v1` → **已废弃**，本轮起初始化时会 `removeItem` 清掉
- **数据结构**：一天一条 = `{d:"YYYY-MM-DD", p:<俯卧撑总数>, w?:"体重", a?:臂围, note?:备注, items?:[{id,v,u,n}]}`。`items` 存动作 id + 数值 + 单位 + **名称快照**（自定义动作删除后历史仍显示原名）。老 19 条自动映射成标准俯卧撑。训练项与身体指标分开存，方便以后加动作。
- **主题**：CSS 变量 `--surface/--card/--ink/--sub/--accent` 等 + `body.dark`；`applyTheme()` 依据 `THEME` 和 `matchMedia('(prefers-color-scheme: dark)')`，监听 `change` 实时切换。
- **图表**：手写 SVG，柱状图 `onclick="pickStatDate(...)"` 透明 hit rect；体重折线 `bindWeightChart()` 绑 touchstart/touchmove/mousedown/mousemove，`weightIndexAt(clientX)` 找最近点，浮层用绝对定位百分比。
- **导入**：JSON 备份或正则解析 `(\d{1,2})\.(\d{1,2})` + `俯卧撑\s*(\d+)` + `体重`/`臂围`。
- **正式版动态化**：`NOW=new Date()`、`TODAY` 实时；`curMonth=[NOW.getFullYear(), NOW.getMonth()+1]`；图表坐标文字、KPI 里的 `10/31 与 11/08`、`10/27 起` 全部实时计算。注意日期格式**带补零**（`11/08` 不是 `11/8`），曾专门对齐过。
- **本轮移除换 Logo 涉及**：删 `.logo-acts`/`.logo-note` CSS、关于页「App 图标」行与说明、`#logoFile` 文件选择器、`getLogo/applyLogo/pickLogo/onLogoFile/resetLogo/LKEY` 全部 JS、导出 payload 的 `logo` 字段、导入里的 `j.logo` 分支、初始化的 `applyLogo()`；`<img data-logo>` 改为直接 `src="icons/icon-512.png"`（开屏与关于页各一处）。favicon/apple-touch-icon 本来就是 HTML 里写死的，不受影响。移除后残留关键词检查通过、`node --check` 通过、运行时诊断 0 报错。

## 8. ⚠️ 未完成的两件事（你要接着做的）

### A. 上传到 GitHub
**云端卡住的原因**（不是代码问题）：
- `github-connector` 的 token 网关返回 `Connector "github" is not authorized for this user or project. Complete connector authorization first.`（HTTP 404）
- `mcp__sandbox_proxy__list_installed_plugins` 里本会话只有 `a2a`、`spaceengine`，**没有 github 连接器**
- `reconnect_plugin` 报 `connector is not in this session`，`workbuddy_request_mcp_connection` 同样报不在会话里（建议 `search_plugins` / `suggest_plugin_install`，当前工具集里没有）
- `gh auth status` 未登录；`github.com` 直连 `000`（不通）；`api.github.com` 未认证时限流 403，带无效 token 返回 401（说明 API 可达，只缺凭据）
- 结论：**要么让用户在 WorkBuddy 设置页「连接器」处授权 GitHub 后重跑 `get_token.sh`，要么在本地电脑上做**（本地网络正常、`gh` 已登录即可）。推荐本地。

本地做法见 `本地运行与打包.md` 第 2 节。仓库建议名 `PUSHUP`，public，推 `app/` 里的源码 + README（本包 README 可直接用）。

### B. 打包成 APK
**云端卡住的原因**：`maven.google.com` 返回 `000`（不通），`dl.google.com` 可达但 Android commandlinetools 153MB 下载被用户中断前只下到 55MB；已主动停掉后台任务避免占资源。系统有 JDK 20（Zulu）、Gradle、Node 22，但**没有 Android SDK**（无 `aapt2`/`d8`/`zipalign`/`apksigner`/`sdkmanager`）。

**推荐方案：WebView 壳 + 本地 assets**（PWA 全部文件塞进 APK 的 `assets/`，不依赖线上链接、不受 sharecode 访问控制影响、离线完整可用、不需要 Digital Asset Links）。因为线上链接带 `?sharecode=` 访问控制且有 assetlinks 域名验证问题，TWA/Bubblewrap 那条路不通，别走。

具体命令、目录结构、签名步骤见 `本地运行与打包.md` 第 3 节。若本地装了 Android Studio，直接用更省事。
