# 给本地 AI 的提示词 · 直接复制粘贴

> 用法：在本地电脑用 WorkBuddy / CodeBuddy / Cursor / Claude Code 等打开解压后的文件夹，
> 把下面这一整段（或指明让它先读 `交接文档-给AI.md`）作为第一句话发过去。
> 这样它不用你重新讲一遍需求，就能直接接着做。

---

```

当前状态、以及还没做完的事，里面全写清楚了。读完再动手，别重新问我已经定过的东西。

【当前状态】
- 正式版已上线：https://a921090d771d09e84.app.workbuddy.host/?sharecode=4IMFZU5IGF
- 源码在 app/：index.html 是单文件 PWA，纯前端 + localStorage，无后端、离线可用
- app/icons/ 是默认橙色 P 图标（用户已确认就用这个，不要换）
- 本轮已完成：移除了「更换 Logo」功能（正式版不允许用户自己换图）、
  sw.js 缓存升到 v2、线上已重新发布、运行时诊断 0 报错

【请帮我接着做这两件事】具体命令看《本地运行与打包.md》

   不要用 Bubblewrap / TWA：线上链接带 ?sharecode= 访问控制、还缺 Digital Asset Links 验证，那条路走不通。

【约束，别踩】

- 我是普通用户，不是开发者：每一步用大白话说明，别堆术语；改完给我能点开 / 能装的文件和效果预览
- 数据只存在浏览器本地，不上传、不同步；换设备靠「导出 JSON → 导入」

先跟我说你打算怎么做、需要我准备什么（比如 Android Studio、GitHub 登录），确认后再动手。
```
