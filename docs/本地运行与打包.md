# 本地运行与打包指南

> 全部命令都在**你自己的电脑**上跑。云端沙箱里 `github.com` / `maven.google.com` 不通、GitHub 连接器未授权、Android SDK 没装，所以这两件事在本地做更顺。
> 假设交接包解压到了 `~/PUSHUP-项目交接包`（Windows 就是 `D:\PUSHUP-项目交接包`），下文用 `cd ~/PUSHUP-项目交接包/app` 进入源码目录。

---

## 第 0 步：装好三个东西（只装一次）

| 工具 | 用途 | 下载地址 | 验证命令 |
|---|---|---|---|
| **Node.js 18+** | 起本地服务、Capacitor 打包 | https://nodejs.org | `node -v` |
| **Git** | 传 GitHub | https://git-scm.com | `git --version` |
| **GitHub CLI（gh）** | 一行建仓库，可选 | https://cli.github.com | `gh --version` |
| **JDK 17 + Android Studio** | 打 APK 用 | https://developer.android.com/studio | `java -version` |

> 只是想在电脑上看看 / 用起来 → 只需要第 1 节，装个 Python 或 Node 就行，甚至不用装。
> 只是想传 GitHub → 第 0 步的 Git 就够了。
> 要打 APK → 必须装 Android Studio（它会自带 Android SDK、JDK、Gradle）。

## 第 1 节：在自己电脑上打开这个 App

### 方式 A：最简单，直接双击（适合快速看）

双击 `app/index.html`，浏览器就打开了。
⚠️ 但用 `file://` 打开时，**离线缓存（Service Worker）不生效**，且个别浏览器会限制本地存储。**只适合看样子，别拿它正式记数据。**

### 方式 B：起个本地服务（推荐，和线上行为一致）

```bash
cd ~/PUSHUP-项目交接包/app

# 有 Python 就用这个（Mac / Linux 自带，Windows 装了 Python 也有）
python3 -m http.server 8080
# Windows 如果 python3 不行，试： python -m http.server 8080

# 或者用 Node
npx serve -l 8080
```

然后浏览器打开 **http://localhost:8080** 。
此时 `sw.js` 会正常注册，离线可用、能「添加到主屏幕 / 安装应用」。

### 想在手机上同一 WiFi 里打开

```bash
# 先查电脑局域网 IP
# Mac/Linux: ifconfig | grep inet    Windows: ipconfig
python3 -m http.server 8080 --bind 0.0.0.0
```
手机浏览器访问 `http://电脑IP:8080`（例如 `http://192.168.1.5:8080`）。
注意：`http://` 非 localhost 时浏览器不给装 PWA，但打开用没问题；要装 PWA 得配 HTTPS。

### ⚠️ 数据提醒

打开的这一份是**预置了最初 19 条历史数据的干净副本**，和线上版的数据互不相通。
如果你在线上版里录过新数据：线上「我的 → 导出备份 JSON」→ 下载 → 本地「我的 → 导入数据」粘贴进去。

## 第 2 节：上传到 GitHub

### 方式 A：用 gh 一行搞定（推荐）

```bash
cd ~/PUSHUP-项目交接包/app

gh auth login                       # 浏览器里授权一次，按提示选 HTTPS
git init
git add .
git commit -m "PUSHUP v1.0 · 俯卧撑训练记录 PWA"

# 建公开仓库并推送（把 app/ 整个作为仓库根）
gh repo create PUSHUP --public --source=. --remote=origin --push
```

完成后 `gh repo view --web` 直接打开仓库页面。

### 方式 B：不用 gh，手动建仓库

1. 打开 https://github.com/new ，仓库名填 `PUSHUP`，选 Public，**不要**勾选初始化 README / .gitignore（避免冲突），点创建。
2. 本地执行：

```bash
cd ~/PUSHUP-项目交接包/app
git init
git add .
git commit -m "PUSHUP v1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/PUSHUP.git
git push -u origin main
```

### 建议顺手加一个 README

把本包的 `README-先看这里.md` 复制成 `app/README.md` 再提交即可（或让本地 AI 帮你写一份带截图的项目介绍）。
另外建议加 `.gitignore`（内容写 `node_modules/`、`android/`、`*.apk` 就行），免得以后打包把构建产物传上去。

### 想让 GitHub 直接能当网页打开（可选）

仓库 Settings → Pages → Source 选 `main` 分支 / 根目录 → Save，
等一两分钟就有 `https://你的用户名.github.io/PUSHUP/` 可访问。
⚠️ 注意 index.html 里图标、manifest 都是**相对路径**，放子目录也能正常用，不用改代码。

## 第 3 节：打包成 Android APK

### 先说结论：用 Capacitor，不要用 TWA / Bubblewrap

| 方案 | 能不能用 | 原因 |
|---|---|---|
| **Capacitor（WebView 壳 + 本地 assets）** | ✅ **推荐** | 整个 `app/` 塞进 APK，纯本地、离线完整可用，不依赖线上链接 |
| Bubblewrap / Trusted Web Activity | ❌ | 需要线上 HTTPS 地址 + `assetlinks.json` 域名验证；而线上链接带 `?sharecode=` 访问控制，抓不到也验不了 |
| 直接把 PWA 网址做成快捷方式 | ❌ | 那不是 APK |

APK 里跑的还是同一个 `index.html`，**localStorage 在 WebView 里正常可用**，数据存在 App 内部，卸载才会没。

### 3.1 准备（装好 Android Studio 后）

打开 Android Studio → 第一次启动会引导你装 **Android SDK（API 34 或 35）**、**SDK Build-Tools**、**JDK**。装完记下 SDK 路径（Settings → Languages & Frameworks → Android SDK → Android SDK Location），一般是：
- Windows：`C:\Users\你\AppData\Local\Android\Sdk`
- Mac：`~/Library/Android/sdk`
- Linux：`~/Android/Sdk`

把环境变量配上（后面 Gradle 要用）：

```bash
# Mac / Linux，写进 ~/.zshrc 或 ~/.bashrc
export ANDROID_HOME=$HOME/Library/Android/sdk      # Linux 改成 ~/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools

# Windows PowerShell（当前用户永久生效）
[Environment]::SetEnvironmentVariable("ANDROID_HOME","C:\Users\你\AppData\Local\Android\Sdk","User")
```

验证：`adb --version` 能出版本号就对了。

### 3.2 用 Capacitor 生成 Android 工程

```bash
cd ~/PUSHUP-项目交接包

npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android

# 初始化：appId 换成你自己的（上线后不能改，建议 com.你的名字.pushup）
npx cap init "PUSHUP" "com.pushup.app" --web-dir=app

# 加 Android 平台（会生成 android/ 目录）
npx cap add android
npx cap sync
```

`npx cap init` 会生成 `capacitor.config.ts`（或 .json），确认里面 `webDir: 'app'` 指向的就是含 `index.html` 的那个目录。

**几个必须处理的点：**

1. **关掉 Service Worker 注册**（APK 里资源本来就在本地，不需要 SW，且 `http://localhost` 下注册容易报错）。
   在 `app/index.html` 的 JS 里找到这段并注释掉（**只改 APK 用的这一份，别动线上那份**）：
   ```js
   // if("serviceWorker" in navigator && location.protocol!=="file:"){
   //   window.addEventListener("load",()=>{navigator.serviceWorker.register("sw.js").catch(()=>{});});
   // }
   ```
   更省事的做法：让本地 AI 帮你把 `app/` 复制一份成 `app-apk/`，改这个副本，`webDir` 指向 `app-apk/`。

2. **深色模式 / 跟随系统**：WebView 里 `prefers-color-scheme` 一般跟随系统，App 内的三档切换照常可用。

3. **开屏励志语**：App 自带的那层开屏会正常显示；Android 系统启动白屏可在 Capacitor 里配 `launchScreen`（可选，不影响功能）。

4. **图标**：把 `app/icons/icon-512.png` 交给 [`@capacitor/assets`](https://github.com/ionic-team/capacitor-assets) 一键生成各尺寸启动图标：
   ```bash
   npm install --save-dev @capacitor/assets
   npx capacitor-assets generate --android   # 需要一张 1024×1024 的源图放 assets/icon.png
   ```
   或者先不弄，用 Capacitor 默认图标也能装，之后再换（**用户已确认就用默认橙色 P 标**）。

### 3.3 构建 APK

```bash
cd ~/PUSHUP-项目交接包
npx cap copy android          # 每次改了网页代码都要跑一次
cd android

# Mac / Linux
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

产物在：
```
android/app/build/outputs/apk/debug/app-debug.apk
```

**这个 debug APK 可以直接装到手机上用**（自带 debug 签名，不需要额外配置）。传到手机（微信/QQ/数据线都行）点开安装，允许「未知来源」即可。或连着数据线：

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### 3.4 要上架 / 发酷安，出正式签名包

```bash
# 生成签名密钥（只做一次，密码和文件务必备份，丢了就没法升级 App）
keytool -genkey -v -keystore pushup-release.jks -alias pushup \
  -keyalg RSA -keysize 2048 -validity 10000
```

在 `android/app/build.gradle` 的 `android { ... }` 里加：

```groovy
signingConfigs {
    release {
        storeFile file("../../pushup-release.jks")
        storePassword "你的store密码"
        keyAlias "pushup"
        keyPassword "你的key密码"
    }
}
buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled false
    }
}
```

然后：
```bash
./gradlew assembleRelease
# 产物：android/app/build/outputs/apk/release/app-release.apk
```
更省事：Android Studio 菜单 **Build → Generate Signed App Bundle / APK** 按向导点也能出。

## 附：常见问题

| 现象 | 原因 / 解法 |
|---|---|
| `gradlew` 报 SDK 找不到 | 检查 `ANDROID_HOME`，或在本包根目录建 `android/local.properties` 写 `sdk.dir=C\:\\Users\\...\\Sdk` |
| 打开 APK 白屏 | 多半是 `webDir` 指错了，或忘了 `npx cap copy`；确认 `android/app/src/main/assets/public/index.html` 存在 |
| 装不上 / 解析包错误 | debug 包要允许「未知来源」；或 Android 版本过低（Capacitor 要求 Android 6+ / API 23+） |
| 想保留线上版继续用 | 不用管，线上链接一直有效，和本地 / APK 三份数据各自独立 |
| 三份数据想合并 | 各自「导出 JSON」→ 在目标端「导入数据」，同日期会覆盖合并 |
